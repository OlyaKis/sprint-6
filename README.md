Этот проект предназначен для автоматизированного тестирования функциональности сайта для заказа самокатов "Яндекс Самокат". Автотесты написаны на Python с использованием библиотеки Selenium.

Тестируется:

tests_order:
Страница заказа: флоу позитивного сценария с двумя наборами данных. Проверены точки входа в сценарий, их две: кнопка «Заказать» вверху страницы и внизу.
Также есть тесты на работу кнопок-логотипов в левом углу: 
 - если нажать на логотип «Самоката», попадёшь на главную страницу «Самоката»
 - если нажать на логотип Яндекса, в новом окне через редирект откроется главная страница Дзена

tests_main_page:
Проверен выпадающий список в разделе «Вопросы о важном»: когда нажимаешь на стрелочку, открывается соответствующий текст. Написаны тесты на каждый вопрос отдельно.
